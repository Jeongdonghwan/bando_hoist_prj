## 수신기가 펜던트 버튼을 대신 눌러 주게 만드는 작업입니다

호이스트 무선리모컨 설치 절차는 여섯 단계로 나뉩니다. 기존 조작 회로를 확인하고, 수신기를 달 자리를 정해 고정하고, 수신기의 출력을 조작 회로에 잇고, 비상정지를 주 접촉기 회로에 넣고, 펜던트와 리모컨을 가려 쓰는 전환을 구성한 다음, 모든 동작과 안전장치를 시험합니다. 원리는 단순합니다. 펜던트 버튼이 하던 접점 연결을 수신기 안의 릴레이가 대신하게 하는 것입니다.

## 달기 전에 확인하는 것

리모컨이 맞물릴 곳은 호이스트의 조작 회로입니다. 펜던트 버튼을 누르면 조작 전압이 접촉기 코일로 가서 모터를 돌리는데, 수신기도 같은 전압으로 같은 코일을 움직여야 합니다. 그래서 조작 전압이 얼마인지, 수신기 전원을 어디서 딸 수 있는지를 먼저 봅니다.

동작 수도 셉니다. 올림과 내림, 횡행 두 방향, 주행 두 방향, 여기에 2단 속도가 있으면 단수만큼 접점이 더 필요합니다. 경광등이나 보조 훅 같은 부가 기능도 포함해 송신기 버튼 구성과 수신기 출력 수를 맞춥니다.

오래된 소형 호이스트 가운데는 접촉기 없이 펜던트 버튼이 모터 전류를 직접 끊고 잇는 방식이 있습니다. 이런 장비는 수신기 릴레이로 바로 대신할 수 없어 접촉기 회로를 새로 꾸며야 합니다.

## 설치 순서

- 전원 차단과 기록: 훅을 비우고 분전반 차단기를 내려 잠급니다. 제어함 안 배선을 사진으로 남기고 회로도와 대조합니다.
- 수신기 고정: 진동과 열이 적고 송신기 쪽으로 가려지지 않는 자리에 답니다. 제어함 가까이 두어 배선을 짧게 하되 정비할 때 손이 닿아야 합니다.
- 출력 배선: 수신기의 각 릴레이 출력을 해당 방향의 조작선에 연결합니다. 선마다 표시를 붙입니다.
- 비상정지 연결: 송신기의 정지 버튼과 수신 끊김이 주 접촉기를 떨어뜨리도록 연결합니다. 방향 신호만 끊기는 구성으로는 부족합니다.
- 전환 구성: 펜던트를 남긴다면 선택 스위치로 한쪽만 살아 있게 합니다. 둘이 동시에 먹으면 서로 반대 방향을 누르는 일이 생깁니다.
- 안테나와 마감: 안테나가 철판에 가려지지 않게 하고, 케이블 인입구를 막고 배선을 묶습니다.

## 시험은 빈 훅으로, 하나씩

전원을 넣기 전에 배선을 다시 대조합니다. 그다음 빈 훅으로 각 버튼을 짧게 눌러 표시된 방향대로 움직이는지 봅니다. 방향이 바뀌어 있으면 그 자리에서 바로잡습니다. 2단 속도가 있으면 반 누름과 끝 누름을 따로 확인합니다.

안전 기능 시험이 더 중요합니다. 움직이는 도중 송신기 정지 버튼을 눌러 서는지, 송신기 전원을 끄거나 건전지를 빼면 서는지 봅니다. 상한과 하한 리미트, 주행 리미트가 리모컨 조작에서도 그대로 작동하는지 확인합니다. 리미트를 거치지 않고 접촉기로 바로 들어가게 이으면 리모컨으로 조작할 때만 리미트가 듣지 않게 됩니다.

마지막으로 작업장 끝에서 끝까지 걸으며 끊기는 자리가 없는지, 같은 공장의 다른 리모컨과 서로 간섭하지 않는지 봅니다.

## 설치 뒤 인계할 것

송신기 버튼의 방향 표시가 실제 방향과 맞는지 확인하고, 크레인이나 건물에 같은 방향 표지를 붙입니다. 리모컨은 작업자가 서는 위치가 자유로워서 방향을 헷갈리기 쉽습니다. 송신기 보관 자리, 충전이나 건전지 교체 방법, 잃어버렸을 때의 연락 순서를 정해 둡니다. 바꾼 배선은 회로도에 적어 제어함 안에 넣어 두세요. 다음에 수리하는 사람이 수신기가 어디에 물려 있는지 알 수 있어야 합니다.

제어함 안 결선은 충전부를 다루는 일이라 작업자가 직접 할 일이 아닙니다. 전원을 끊고 잠근 상태에서 정비 인력이 합니다.
